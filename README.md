# Advanced Portfolio App

A professional, multi-feature web application built with HTML, CSS, and JavaScript. This project combines five practical apps into a single, modern portfolio-ready sample:

- **To-Do List App**: Create, mark as done, and delete tasks. Data is stored in the browser (localStorage).
- **Weather App**: Fetches live weather data for any city using the Open-Meteo public API.
- **Unit Converter**: Convert between length (meters/feet), weight (kg/lb), and currency (USD/EUR) using exchangerate.host API.
- **Personal Portfolio**: Showcase your skills, projects, and resume.
- **Calculator App**: Clean, interactive UI for basic math operations.

## Features
- Responsive, modern design
- Modular, well-commented code
- No frameworks required (pure HTML/CSS/JS)
- API integration for real-world data
- Ready to deploy on any static web server

## How to Use
1. Place the `advanced-portfolio-app` folder in your web server directory (e.g., `htdocs` for XAMPP).
2. Open `index.html` in your browser.
3. Explore each feature using the navigation bar.

## Customization
- Update your name, skills, and resume link in the Portfolio section (see `app.js`).
- Add more features or improve UI as desired.

## Deployment
- Host on any static server (XAMPP, Apache, Nginx, GitHub Pages, Netlify, Vercel, etc.).
